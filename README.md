# Hermes Podcast

每日 AI 科技新聞與國際新聞語音摘要（中英文），由 GitHub Actions 於每天 08:17 起（台北，另有 08:47、09:47 備援）自動產生。

- 訂閱網址：https://ch88chen.github.io/hermes-podcast/feed.xml
- `main`：程式碼（`podcast/build.py`、`.github/workflows/daily.yml`）
- `gh-pages`：音檔與 feed（每次發佈為單一 commit，保留 14 天）
- 手動執行：Actions → Daily podcast → Run workflow
